# TypePaws 🐾
### Cute & Modern Touch-Typing Academy

A modern, responsive typing practice website designed with a playful personality and cute visual style. Featuring **Barnaby the Whimsical Cat** as your animated typing companion who reacts dynamically as you type, makes hilarious cartoon faces when you hit a wrong key, and celebrates your victories with confetti!

---

## 🌟 Key Features

### 1. Three Comprehensive Learning Paths
Upon starting, learners choose their current typing level:
- **🐾 Beginner: Kitten Steps** (Lessons 1–100): Starts from home row anchor keys (`ASDF` & `JKL;`), reaches up to top row and down to lower row, introduces capitalization with Shift keys, and concludes with fluent natural English sentences.
- **⚡ Intermediate: Cattitude Cruise** (Lessons 1–100): Advances from intermediate to advanced skills with punctuation, quotes, contractions, high-frequency digraphs (`-tion`, `-ment`, `-ough`), the number row, and real-world paragraph sprints.
- **🔥 Advanced: Sonic Claws** (Lessons 1–100): Dedicated to blind touch typing without looking at the keyboard! Includes awkward finger gymnastics, code syntax (JavaScript, Python, HTML/CSS, SQL), tricky tongue twisters, and grandmaster speed marathons.

Each level is organized into **5 curated sections of 20 lessons each**, totaling **100 progressive practice modes per level** (300 total curated lessons!).

### 2. Practice Arena & Real-Time Engine
- **Character-by-character live highlighting**: Correct letters glow in soft mint green; mistakes show in coral red with a subtle shake animation.
- **Smooth animated caret cursor**: Follows your keystrokes across lines.
- **Live Stats Bar**: Instant real-time calculation of **WPM**, **Accuracy %**, **Elapsed Time**, and **Errors Count**.
- **Timer Modes**: Practice in Passage Completion mode or race against the clock in 15s, 30s, or 60s sprint modes.
- **Dual Input Support**: Works on desktop physical keyboards and tablet/mobile touchscreens with transparent accessible input.

### 3. Reactive Cartoon Mascot & Funny Error Reactions
- **Dynamic Animated SVG Character**:
  - **Idle**: Gentle breathing and tail wagging.
  - **Typing**: Paws tap on a mini laptop; anime smile eyes; speed sparkles at >55 WPM!
  - **Wrong Key Reaction**: **A brief, funny cartoon animation!** Eyes widen in comic shock `(◎ _ ◎)`, a cartoon sweat drop pops, mascot wobbles (`bonk!`), and a witty speech bubble quip appears (*"Oopsie! 🐾"*, *"Bonk! 😹"*, *"Wrong paw! 😸"*). Instantly recovers in 450ms so typing flow is never interrupted.
  - **Victory**: Celebratory dance, party hat, and confetti shower!
- **Mascot Skins**: Switch between Barnaby the Cat 🐱, Pip the Hamster 🐹, and Bubbles the Blob 💧 in Settings.

### 4. Interactive Touch-Typing Virtual Keyboard
- Color-coded finger zones (Left Pinky to Right Pinky and Thumbs).
- Highlights the exact target key and opposite Shift key for the current character.
- Haptic key-press animations.
- Can be toggled on/off with one click.

### 5. Web Audio API Synthesizer
- Built-in sound effects without external audio file dependencies:
  - Crisp mechanical switch clacks (subtle and satisfying).
  - Cartoon "boop" error sound on mistake.
  - Streak chime and 5-note victory fanfare.
  - Audio theme choices: Mechanical, Cute Marimba, Water Bubble Pop, or Off.

### 6. Friendly Dashboard & Persistence
- **Performance History Chart**: HTML5 Retina Canvas line chart plotting WPM progression over time.
- **Resume Next Lesson**: One-click hero button to jump straight back into practice where you left off.
- **Badges & Milestones**: Unlock achievements like *First Clack*, *Home Row Hero*, *Speed Cheetah*, *Sonic Claws*, and *Purr-fect Bullseye*.
- **Dark Mode**: Silky smooth toggle between sunny pastel light mode and cozy midnight dark mode.
- **Local Persistence**: Saves all lesson completion stars, best WPM, accuracy, and streaks in `localStorage`.

## 🚀 Quick Start

Open `index.html` directly in any web browser:
```bash
# Simply double-click index.html or run:
start index.html
```

Or run using Python's built-in local server:
```bash
python -m http.server 3000
# Then visit http://localhost:3000 in your browser
```

Or via Node / NPM:
```bash
npm start
```
